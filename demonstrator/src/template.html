Presenting with this

  1. Start on Architecture and click through the components.
  2. Open a flow tab. The briefing covers the actors, the setup and the anti-pattern before anything moves.
  3. Press Start. Each hop lights up and the packet moves between components. The inspector has the request, the response, the tokens and the checks.
  4. Flip to Live to run the same flow against a real Entra test tenant. That needs the local server.
